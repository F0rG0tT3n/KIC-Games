# 2048

Open **Singleplayer > 2048 > Play**, or use `/kic2048`.
The supplied `Media/2048/2048-hero.tga` and `2048-card.tga` are used in Home's
featured presentation, the Singleplayer library and Recent Games.

Slide the entire 4 x 4 board in one direction. Equal adjacent tiles combine;
each original tile can merge only once in a move. A merge adds the new tile's
value to your score. A successful move creates a new tile: 2 with 90% probability,
4 with 10%. A blocked direction does not count as a move and creates no tile.
New runs begin with two tiles and zero points.

- **Mouse:** hold the left button anywhere on the board, drag in a direction,
  then release. The dominant axis determines the direction; small click jitter
  is ignored. Each drag makes one move, including releases outside the board.
- **Keyboard:** arrows or WASD, one move per key press. Typing in chat or an edit
  field takes priority. Hiding the board, changing its scale or resizing cancels
  an unfinished drag.
- **New game:** immediately starts a fresh board. **Share best** explicitly sends
  your saved score to the same group-chat/SAY destination as the existing games.

Tile slides, merges and new-tile appearances animate. Inputs are blocked while
a move resolves. Reach **2048** to win the run; a full board with no adjacent
equal tiles ends in a loss. The final board remains in the main window, with a
Bejeweled-style result popup showing score, best, highest tile and move count.
Use **Play again** or **Back to menu**, or close the popup to inspect the board.

Best scores are saved in `KICGamesDB.game2048.best`, including the highest tile
and move count from that run. Completed runs enter the shared result history;
restarting an unfinished run uses the existing abort lifecycle. The active
board survives launcher navigation but is not restored after `/reload`.

The module lives in `KIC-Games/Games/2048/`: `Engine.lua` holds pure rules and
animation metadata, `UI.lua` owns board/input/animation, and `Module.lua` handles
registration, lifecycle and saved data. Artwork is registered centrally.

Run `lua tests/game2048.lua` and `lua tests/game2048_ui.lua` from the repository
root. Tests cover every direction, single-merge rules, spawning/no-ops, win/loss,
mass preservation, scaled gestures, outside releases, cancellation, keyboard and
chat focus, animation gating, results, replay, persistence and game switching.
Offline renders check the UI layout; mouse handling and texture loading still
need a smoke check in the WoW client.
