These are the exact installed original Blindshot TGAs, preserved before runtime
normalization. The supplied hero was 1774×887 and the card 1254×1254. Runtime
textures use the same content resized to 1024×512 and 256×256 for WoW.

Run `python tools/normalize_blindshot_art.py` from the repository root to reproduce
the runtime files. The originals and reference PNGs are development assets and
must remain outside the installable inner `KIC-Games` folder.
